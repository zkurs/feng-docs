---
title: "VoiceMaster"
description: "Set up personal voice rooms and safe owner controls."
---

## Create the interface

Setup creates the join-to-create flow and owner controls. Feng needs channel-management access in the target category.

```text
,voicemaster setup
```

## Room access

Room owners can permit or disconnect members without receiving server-wide moderation permissions.

```text
,voicemaster permit @member
```

## Defaults

```text
,voicemaster default limit 5
```
