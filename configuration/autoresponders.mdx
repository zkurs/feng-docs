---
title: "Autoresponders"
description: "Create useful automatic replies without matching ordinary conversation."
---

## Create a trigger

Prefer short, intentional phrases that members are unlikely to type by accident.

```text
,autoresponder add hello Welcome to the server
```

## Review and remove

```text
,autoresponder list
,autoresponder remove hello
```

## Test safely

Test in a private channel first. Check capitalization, punctuation, and whether the response could ping roles or users unexpectedly.
