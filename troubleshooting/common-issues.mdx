title: "Common issues"
description: "Work from the visible symptom to the underlying cause."
---

## The command does not respond

Confirm the current prefix, check that the command exists, and make sure Feng can view and send messages in the channel.

## The command responds but cannot act

Check the moderator's access, Feng's Discord permission, and both role positions. The server owner and members above Feng remain protected by Discord.

## An integration is unavailable

External providers can fail independently. Retry later, confirm the account is linked, and check [Feng Status](https://feng.up.railway.app/status).

## Still stuck

Collect the command, exact response, channel, and relevant role positions before asking for help. Never post tokens, client secrets, or private transcript links.
